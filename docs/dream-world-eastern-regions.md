# 东部梦境区域：回忆与连接

## 用户提供的回忆

- 湖泊在整体梦境的东北角，不能向西离开，只能向南离开。
- 湖泊南边是小吃街，街道氛围参考济南宽厚里。
- 小吃街店铺很多，其中有一家中药房，门口有一只蓝色小狐狸。
- 小吃街再往南是整体地图东部的巨大商场，进入室内场景。
- 商场没有连接小吃街的北门。西门接街道马路，东门接室外体育场，南门接车道马路。
- 商场室内细节由用户后续提供。

## 本轮区域连接

```text
                 东北湖泊（只有南出口）
                      ↕
                    小吃街
                      ↕
                  西侧街道 ⇄ 商场 ⇄ 室外体育场
                      ↕       ↕ 南门
                      └── 南侧车道
```

湖泊、小吃街之间沿南北方向往返。小吃街南端先接商场西侧街道，再从西门入内；这是为落实“商场没有北门”采用的连接方案，具体街巷尺寸可随后续回忆调整。商场北墙全部阻挡，未设置入口。所有出口都配有方向箭头，踏入后淡出切换；目标出生点位于入口内侧，不会立即弹回原场景。

## 画面与范围

- 保持 48px 精细可复用图块与逐格移动。
- 小吃街：灰砖、瓦檐、木框窗、石板路、灯笼，六家店铺。
- 中药房为明确回忆地标；其他烧饼、面食、茶饮、糕点、小食招牌是布景用通用名称，不代表已确认的具体店名。店铺内部尚未制作。
- 蓝色小狐狸有独立像素形象，固定在中药房门外，可相邻互动；未赋予名字、身世或任务。
- 商场：较大的室内空间、基础地面与墙体、三处出入口；不添加店铺、楼层或剧情。
- 体育场与车道先做可识别、可通行的基本场景；跑道、场地线和路面标线属于基础布景，可在用户补充后修改。

## 数据与存档

`dreamRegions.js` 定义六个场景的地图、入口、出口与双语说明；`dreamRegionRenderer.js` 复用湖畔纹理并添加城市图块与建筑外观。移动和存档恢复按当前场景的地图计算，不再用湖畔碰撞规则处理其他场景。

存档仍使用版本 3 的既有字段：当前场景、入口、位置、已发现场景、碎片、钓鱼记录和教程进度。没有增加新的存档结构。场景切换由 React 重建 Phaser 场景，旧渲染、输入与计时器随场景销毁。

测试覆盖所有区域可达性、双向出口、出生点不重叠出口、湖泊仅南出口、商场无北门、小狐狸位置、跨区域往返和刷新存档恢复。
