# 东北湖畔：复用图块与逐格移动

## 当前地图

- 32 × 24 格，每格 48 × 48 屏幕像素；地形图块以原生 48 × 48 像素绘制。
- 草地、花草、石路、湖岸和木栈台各有四个纹理变体；湖水采用四帧动画。地面不绘制格子边框，仅在地形交界处添加草叶和水岸过渡。
- 树木使用 80 × 100 像素的独立树冠、树干与阴影图层，按人物脚下位置处理前后遮挡；树和岩石各有三个纹理变体。
- 地形由 `lakesideMap.js` 的地图数据组合，不再加载整张 `threshold-meadow.png` 背景。
- `lakesideTiles.js` 保存原创像素图块配方，在场景启动时生成纹理并复用；无需外部图块授权。
- 保留原有角色素材，调整人物比例，使人物脚下位置对应所在格中心。
- 地图格定义同时驱动画面与阻挡规则，不能通过湖水、树木或岩石。

| 地图符号 | 图块 | 可走 |
|---|---|---|
| `.` | 草地 | 是 |
| `,` | 草丛 | 是 |
| `*` | 花草 | 是 |
| `=` | 小路 | 是 |
| `:` | 湖岸 | 是 |
| `~` | 湖水，两帧水纹 | 否 |
| `T` | 树木 | 否 |
| `O` | 岩石 | 否 |
| `#` | 木栈台 | 是 |

## 移动与互动

方向键、WASD 和屏幕方向按钮均控制四向逐格移动。每步用 190ms 平滑移动至相邻格中心；轻按走一格，长按连续走格，不能斜走或停在格子之间。NPC 占用的格子不可进入；站在其上下左右相邻格即可交谈。碎片在踏入其所在格后收集。木栈台的钓鱼标记格及相邻格支持垂钓。

对话、记忆说明和重置确认打开时暂停新的步行操作。失去窗口焦点时清除按键，防止恢复焦点后持续行走。

## 存档

存档版本升至 3，接受版本 1、2 和 3。保留人物关系线索、已收集碎片、钓鱼发现和教程状态。旧位置对齐最近的可走格，并排除 NPC 格。每步结束保存一次；刷新或换语言时只恢复完整格子位置。场景和内容 ID 保持不变。

## 修改地图

调整 `lakesideMap.js` 中的格子布局；修改图块外观只需修改 `lakesideTiles.js` 的对应配方。NPC、碎片与钓鱼点在 `dreamWorldData.js` 中使用 `cellToWorld(列, 行)` 放置，列和行从 0 开始。钓鱼浮漂必须落在水格，人物互动点必须在可走格。

运行 `npm test` 会检查地图边界、阻挡、旧存档迁移，以及从出生点到全部碎片、NPC 和钓鱼点的可达性。

目前已扩展为六个手工数据场景，包含双向入口与区域切换。区域拓扑见 [东部梦境区域](./dream-world-eastern-regions.md)。Tiled 导入与流式加载尚未实现；当前通过场景切换按需重建地图。
